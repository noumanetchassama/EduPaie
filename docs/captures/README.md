# Captures d'écran - EduPaie

Ce dossier contient les captures d'écran de l'application EduPaie.

## Captures à inclure

1. **Tableau de bord** : Vue d'ensemble avec les statistiques
2. **Liste des élèves** : Interface de gestion des élèves avec recherche et filtre
3. **Formulaire d'ajout d'élève** : Dialogue pour ajouter/modifier un élève
4. **Dialogue de paiement** : Interface d'enregistrement d'un paiement
5. **Détails de l'élève** : Fiche élève avec historique des paiements
6. **Reçu PDF** : Exemple de reçu généré

## Instructions pour ajouter des captures

- Prenez des captures d'écran de l'application en cours d'utilisation
- Placez-les dans ce dossier
- Mettez à jour ce README pour décrire chaque capture
