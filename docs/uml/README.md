# Diagrammes UML - EduPaie

Ce dossier contient les diagrammes UML du projet EduPaie.

## Diagrammes à inclure

1. **Diagramme de classes** : Représente les classes du système et leurs relations
2. **Diagramme de séquence** : Montre les interactions entre les composants pour les cas d'utilisation principaux
3. **Diagramme de cas d'utilisation** : Décrit les fonctionnalités du point de vue utilisateur

## Instructions pour ajouter des diagrammes

- Exportez vos diagrammes UML depuis votre outil préféré (StarUML, Draw.io, etc.)
- Placez-les dans ce dossier
- Mettez à jour ce README pour décrire chaque diagramme
